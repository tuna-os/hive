- Agents can no longer read the dashboard token, which the dashboard API accepts as the owner. Every process the hive starts as an agent's user, above all the agent's tmux server, now gets a short list of allowed variables instead of the hive's whole environment, so the hub secret, the terminal key and the full App installation token are gone from it too. The browser terminal's tmux client starts with a clean environment. ttyd now listens on a unix socket in a directory only the hive's user can enter, with no credential on its command line; set `HIVE_TTYD_BIND` to keep the old loopback/TCP listener. The Go API and the Node proxy also refuse the token from a loopback peer whose socket an agent's user owns. After upgrading, restart every agent's tmux server (a pod restart does it) and rotate the dashboard token.
