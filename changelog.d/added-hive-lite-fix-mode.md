- `hive-lite -fix` (fork): a free-tier model may commit to a `hive-lite/issue-N` branch and open one **draft** PR. Hive applies every patch, and the model holds no credentials. Protected paths are refused, as are whole-file rewrites that drop existing code. `-verify '<cmd>'` builds and tests each patch in a scratch copy before it is committed. A resumed session sees its branch's existing diff. Only one hive-lite draft can be open per issue.
