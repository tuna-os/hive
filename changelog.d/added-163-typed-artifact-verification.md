- `github.Client.VerifyReportedArtifact` verifies reported issue and release URLs as typed, opt-in non-code handoffs ([#163](https://github.com/tuna-os/hive/issues/163)). It checks that the object exists, is the requested kind (an issue URL that is really a PR is rejected), belongs to the assigned repository (matched against the canonical repo, so renames still match and foreign repos never do) and was created by the contributor. Results are `verified`, `rejected` or `unverified`; rate-limit, permission, 5xx and network failures stay `unverified` and earn no credit. Draft and published releases are distinct states, and a task names the sufficient kind/state through `ArtifactAcceptance`. Results carry a canonical `Key` for duplicate detection. PR verification, trust and cooldown behavior are unchanged, and no merged-fix proof is implied.
