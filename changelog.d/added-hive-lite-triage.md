- `hive-lite` (fork): a standalone CLI that runs a default-off, report-only, shadow triage of one issue on free-tier inference gateways (RFC #18464 phase 1). It uses `pkg/hivelite`, `pkg/turn/llmrouter` and `pkg/hivetool`, offers the model read tools only at ADVISORY, and prints the advisory and a JSON result to stdout; it makes GET requests only and never comments, labels, branches, commits or opens pull requests. The issue body is screened by ioscan and pinned in the task, a per-session canary is planted, the session must finish within a turn budget, and the summary's `path:line` citations must point at code the session read.
