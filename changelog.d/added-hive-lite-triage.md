- `hive-lite` (fork): a standalone CLI and `workflow_dispatch` workflow that runs a CLI-less, report-only triage of one issue on free-tier inference gateways. It uses `pkg/hivelite`, `pkg/turn/llmrouter` and `pkg/hivetool`. The issue body is screened by ioscan and pinned in the task, a per-session canary is planted, the session must finish within a turn budget, and the summary's `path:line` citations must point at code the session read. The advisory comment is upserted only with `-post`.
