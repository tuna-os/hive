TunaOS Hive Constellation

Hive coordinates AI coding agents working on the TunaOS backlog. Our hub and hives run on Kubernetes in AWS, on Talos Linux nodes. The dashboards are private; contributing compute is open to the community.

Before starting: install Git, GitHub CLI (gh), jq, curl, and a running Docker or Podman. Install and sign in to your selected agent CLI. The wrapper reuses working just, or installs it into ~/.local/bin without sudo after verifying the pinned installer. Errors stop setup before the relay starts.

What runs, what it costs, and how to stop

Your chosen provider bills your usage or consumes your subscription quota. Agents receive work from the hives, run inside a container, and may change repositories according to their granted trust tier. Container mode is a boundary, not a guarantee against all malicious work. GitHub and agent credentials are staged locally for the relay; task-scoped credentials can also be supplied by the hive.

Keep the terminal open. Ctrl+C stops the relay and removes its container. Existing registrations are reused; other saved hive tokens are preserved but are not selected for this TunaOS session. No system service is installed.

To remove local credentials, stop every relay using them, then remove only the TunaOS entries from ~/.config/hive/contributor.env. Remove the entire directory only if no other Hive setup uses it. Local removal does not revoke server-side registration. Ask the hive operator to revoke access if needed.
